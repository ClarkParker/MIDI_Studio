## 2. Mechanism highlights (majors)

- **Band-in-a-Box**: a text chord sheet drives RealTracks (real recorded audio, time/pitch-warped) across every instrument at once; the 2026 release adds AI-Notes (neural audio→MIDI) on top of 202 new RealTracks / 50 RealStyles. [pgmusic.com/bbwin.htm](https://www.pgmusic.com/bbwin.htm) · [2026 news](https://www.pgmusic.com/news/archives/2025/12/bandinabox_2026_1.html). Forum sentiment on RealTracks is mixed ("didn't sound bad, but not great either" — forum opinion **(unverified)**).
- **Toontrack Bandmate** (EZkeys 2 / EZbass / EZdrummer 3) is the one genuinely different coherence mechanism found: instead of one shared chord engine generating generic parts, you drop in *any* audio/MIDI and each instrument independently finds its own closest pre-recorded match. [EZkeys 2](https://www.toontrack.com/product/ezkeys-2/) · [Bandmate forum](https://www.toontrack.com/forums/topic/ez-keys-2-bandmate/).
- **UJAM**: keyswitch selects the phrase, chord sets the pitch; "Follow Chords" deep-integrates only with Studio One. Gearspace complaint: cannot drag in a whole progression, must transpose chord by chord. [ujam.com](https://www.ujam.com/bassist/royal/) · [Gearspace](https://gearspace.com/threads/ujam-releases-virtual-bassist-2-upgrade.1303441/).
- **Logic Pro Session Players**: the cleanest "shared chord source" design — one global Chord Track (or per-region override) feeds Bass / Keyboard Player and Drummer; ML performance generation with a Regenerate button, fully piano-roll editable afterwards. [Apple support](https://support.apple.com/guide/logicpro/chords-and-session-players-lgcp70dd5af3/mac) · [Sound on Sound](https://www.soundonsound.com/techniques/logic-pro-session-players).
- **Arranger keyboards (Genos2 / Pa5X)**: identical underlying model — multi-track Style files (rhythm/bass/chord/pad/phrase) re-harmonised live, switched via Main A–D variations of rising density plus Intro/Fill/Ending. [Genos2 manual](https://usa.yamaha.com/files/download/other_assets/5/2179945/Genos2_reference_manual_En_B0.pdf) · [korg.com/pa5x](https://www.korg.com/us/products/synthesizers/pa5x/). Recurring complaint that styles feel dated — "hotel lobby entertainer level" (forum opinion). [Yamaha Musicians forum](https://yamahamusicians.com/forum/threads/the-real-issue-with-arranger-keyboards.22074/).
- **Akai MPC Pad Perform**: one pad = one full chord voicing; progressions map across 16 pads with instant key/scale transpose. Known bug: scale resets to C major on power-off. [lofiweekly](https://lofiweekly.com/2026/02/09/akai-mpc-chords-explained-pad-perform-progressions-and-the-fastest-way-to-get-musical-results/).
- **Squarp Hapax**: harmony is a MIDI-FX module per track, not a chord-track-follows-all system — a user explicitly asked the forum whether a "chord follow mode for melodies" exists, implying it is DIY. [manual](https://squarp.net/hapax/manual/modefx/) · [community](https://squarp.community/t/does-hapax-have-a-harmonizer-chord-follow-mode-for-melodies/14046).
- **Scaler 3**: "Motions" (formerly Phrases/Performances/Melodies/Basslines) are pro-musician MIDI clips mapped live to the active chord, now on a multi-lane Arrange timeline. [Plugin Boutique](https://help.pluginboutique.com/hc/en-us/articles/35864679857684-What-s-new-in-Scaler-3).
- **Orb Producer Suite**: Bass/Melody/Arpeggio modules read shared harmony from Orb Chords and regenerate a full arrangement together; KVR users call it "the most musical MIDI generator" (user opinion **(unverified)**). [hexachords.com](https://www.hexachords.com/orb-composer/) · [KVR](https://www.kvraudio.com/forum/viewtopic.php?t=549005).
- **Chord → arp/phrase family** (Cthulhu, Phrasebox 2, ChordPotion): same input, three mechanisms — chord memory bank + step-pattern arp; hand-drawn polyphonic phrase remapped per chord; four parallel sequencer lanes producing arp + bass + rhythm at once. [Cthulhu](https://xferrecords.com/products/cthulhu) · [Phrasebox](https://venomode.com/phrasebox) · [ChordPotion](https://feelyoursound.com/chordpotion/).

## 3. Patterns (what most do the same)

- **Style × Variation × Intensity is the near-universal accompaniment model**: arrangers, Band-in-a-Box, iReal Pro, UJAM and the EZ line all reduce to style / RealTrack / phrase set → variation or section (A–D, verse/chorus) → intensity via wheel, knob or keyswitch height.
- **"Follows chords" never means the same thing twice** — from a project-level Chord Track (Logic, Cubase, Reason + upstream Chord Player) to real-time played-chord recognition with no persistent track (NI Session, UJAM outside Studio One, Cthulhu) to a proprietary chord-sheet format (Band-in-a-Box, iReal Pro).
- **Coherence = "one shared chord source", rarely deeper arrangement logic.** Only Toontrack Bandmate and Scaler 3's multi-lane timeline go beyond "same chord in, everyone plays over it".
- **Recorded realism vs rule-based generation is the main technical split, not AI vs non-AI**: Band-in-a-Box, iReal Pro, UJAM, NI Session, Bandmate, Scaler 3 lean on recorded performances; Orb, InstaComposer, Melodya, Riffer, Cthulhu, Torso T-1 lean on rules/algorithms; only a few (Bass Dragon, Concept) explicitly claim ML training.
- **Melody generators converge on scale/chord-tone + step-leap/contour controls**, not motif development or ML — Melodya's shape/rhythm separation and Captain Melody's tension colouring are the two genuine mechanism variants found.

## 4. Gaps (few/none do; recurring complaints)

- **True cross-instrument arrangement intelligence is absent everywhere** — nothing thins a pad because a fill is coming, or lightens a bass part because the keys just got busier; coherence is "same chord source", never "aware of each other".
- **Persistent, ecosystem-wide chord-track following is rare**: Ableton generators only respect a global Scale; Hapax has no built-in chord-follow-all; UJAM's "Follow Chords" integrates deeply in only one DAW.
- **Post-generation editing is often shallow or all-or-nothing**: UJAM users want to drag in a whole progression instead of transposing chord by chord; MPC users complain scale/key is not remembered; arranger players call built-in styles dated.
- **Few products treat melodic contour as separable from harmonic content** — Melodya is the only one built entirely around that.
- **"Sounds generic" is a latent risk across every recorded-phrase tool** (UJAM, NI Session, Scaler 3, EZ line), since each draws from a finite phrase library — inferred from the repeated "intensity ladder over a fixed phrase set" design rather than stated in the sources (own inference, flagged).
